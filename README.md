# 阿歪小吃店（甲仙碗粿肉粽）

高雄前鎮「阿歪小吃店」非官方粉絲示範站 — 碗粿、肉粽、魚焿。

- 店址：高雄市前鎮區復興三路 127 號  
- 電話：07-331-6779  
- 營業：06:30–15:00（公休請見 [Instagram @a_wai_127](https://www.instagram.com/a_wai_127/)）

## 技術

- React 19 + TanStack Start + Vite 8  
- Tailwind CSS v4  
- Zustand 購物袋  

## 本機開發

```bash
npm install
npm run dev
```

預設 `http://localhost:8080`。

```bash
npm run build
npm run typecheck
```

## 免責

本專案為粉絲向示範網站，非店家官方營運。線上預訂為示意流程，實際訂購請來電或至現場。菜單價格以店家現場公告為準。
